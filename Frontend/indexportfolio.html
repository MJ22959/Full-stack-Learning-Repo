Major Academic Project

Image Caption Generator Using Deep Learning

Built a deep learning model to automatically generate natural language descriptions for input images, bridging computer vision and natural language processing.

Technical Approach

Used pre-trained CNNs (VGG16/InceptionV3) for visual feature extraction paired with an LSTM decoder for sequence generation. Trained on Flickr8k/Flickr30k datasets via TensorFlow and Keras applying beam search and teacher forcing.

Outcome & Learning

Gained deep expertise in neural architectures, transfer learning, tokenization, and evaluation metrics like BLEU scores.

Image Encryption via Rubik's Cube Algorithm

Created an innovative image encryption system utilizing 3D matrix operations inspired by Rubik's Cube permutations to secure digital image transmission.

Technical Approach

Outcome & Learning

Presented as a poster at the 2nd National SET Conference (2019). Mastered cryptographic concepts, image processing, and database optimization.
