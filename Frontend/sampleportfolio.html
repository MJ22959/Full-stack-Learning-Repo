Projects

Here are some of the projects I have worked on.


  • Project 1: Image Caption Generator Using Deep Learning (Major Academic Project)

    This project was my capstone academic project, where I built a deep learning model that could automatically generate natural language descriptions for any image that was provided as input to the system. The two main challenges in building such a system were bridging the gap between computer vision and natural language processing.

    Technical Approach:

    The second part of my algorithm utilized a pre-trained Convolutional Neural Network (CNN) to recognize specific objects within the video frame. These models, such as VGG16 and InceptionV3, are pre-trained on datasets of images with labeled objects, allowing them to learn the visual features of those images. These models can recognize specific objects in videos, even if they have never seen the objects before in their training data.To perform the image-to-text task, I implemented a Long Short-Term Memory (LSTM) network as the decoder for the model. The LSTM took the feature vector of an image as input and generated a sequence of words that corresponded to the image.I worked with the Flickr8k and Flickr30k dataset, which contains thousands of images with multiple reference captions, allowing the model to learn the relationship between visual patterns and descriptive language.This model was created using TensorFlow and Keras in Python. During the training of the model, I applied techniques such as teacher forcing and beam search to improve the quality of the generated captions.

    Outcome & Learning:

    This project provided me with extensive hands-on experience with various neural network architectures, transfer learning techniques and sequence generation models. Also, I gained a deeper understanding of data preprocessing, tokenization and model evaluation metrics such as BLEU scores. The outcome of this project reinforced my interest in applying AI techniques to quality assurance and automated testing processes using computer vision.


  • Project 2: Image Encryption Using Rubik's Cube Based Algorithm (Minor Academic Project)

    In this research-focused project, I created an innovative image encryption system inspired by the fascinating mathematical properties of a Rubik's Cube. The main aim was to boost the security of digital images during transmission or storage, ensuring they remain safe from unauthorized access.

    Technical Approach:

    I crafted an algorithm that viewed an image as a 3D matrix of pixels, applying a series of "rotation" and "permutation" operations—much like scrambling the faces of a Rubik's Cube. This technique effectively shuffled pixel positions and modified color channel values in a way that could be reversed.The encryption key was generated from a specific set of rotation sequences, which made the system robust against brute-force attacks.I built the entire system using Python, leveraging OpenCV for image processing and SQLite for securely storing encryption keys and user metadata.Additionally, the project featured a user-friendly GUI that allowed users to upload images, encrypt or decrypt them, and view the outcomes.

    Outcome & Learning:

    I showcased this project as a poster at the 2nd National SET Conference in 2019, hosted by the Advanced College of Engineering and Management, and it got a great response! This experience really sharpened my skills in cryptographic thinking, image processing, and database integration. Plus, I learned a valuable lesson about the need to strike a balance between security and performance, since encryption processes have to be quick enough to be useful in real-world applications.
